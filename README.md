# EFMS — Maritime ETA & Delay Prediction Platform

EFMS is an independent maritime analytics project focused on using real world AIS vessel data to analyse vessel movements, port activity and operational patterns.

The project is being developed around major U.S. ports and currently includes AIS data cleaning, vessel tracking, port geofencing and vessel-entry event detection. More than 7 million AIS records have been processed during the initial development phase.

The long term goal of this project is to develop predictive features for ETA and vessel delay estimation using indicators such as vessel speed trends, dwell time, port congestion and other operational variables.

## Current used Technologies

- Python
- Pandas
- AIS Data
- Machine Learning
- Maritime Analytics
